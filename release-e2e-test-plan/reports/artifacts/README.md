# Evidence artifacts

Captured evidence referenced by the track reports lands here: logs, packet
captures, SBOMs, scanner JSON, `systemd-analyze` output, GIFs, screenshots.

Name files `track-NN-<what>` (e.g. `track-01-sbom.json`,
`track-06-testssl.txt`, `track-02-concurrency-logs.txt`) so the rollup can trace
each finding back to its evidence.
